# Landing Page

A responsive landing page created as part of The Odin Project Foundations course.

## About

This project is a recreation of the Landing Page design from The Odin Project.  
It contains a navigation bar, hero section, information cards, quote section, call-to-action section, and footer.

## Built With

- HTML5
- CSS3
- Flexbox

## What I Learned

- How to structure a complete webpage with HTML
- How to use CSS classes to style separate page sections
- How to use Flexbox for rows and columns
- How to use `justify-content` and `align-items`
- The difference between margin and padding
- How to create a header, cards, quote section, call-to-action section, and footer
- How to use Git and GitHub for a project

## Features

- Header with logo and navigation links
- Hero section with text, button, and image placeholder
- Four information cards
- Quote and author section
- Call-to-action signup section
- Copyright footer
